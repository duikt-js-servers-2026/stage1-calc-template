# Етап 1. Консольна утиліта `calc`

Дисципліна «JavaScript у створенні серверів» · наскрізний проєкт · **етап 1 з 6** (лабораторні 1–2, захист на лаб. 2, 5 балів)

## Завдання

Реалізуйте у файлі `src/cli.js` консольну утиліту, яка виконує обчислення над числами, переданими як аргументи командного рядка.

```
node src/cli.js <операція> <число1> [число2 ...]
```

### Операції

| Операція | Результат | Приклад | Вивід |
|---|---|---|---|
| `sum` | сума | `node src/cli.js sum 1 2 3` | `6` |
| `avg` | середнє арифметичне | `node src/cli.js avg 2 4 9` | `5` |
| `min` | мінімум | `node src/cli.js min 3 -1 2` | `-1` |
| `max` | максимум | `node src/cli.js max 3 -1 2` | `3` |
| `median` | медіана (для парної кількості — середнє двох центральних) | `node src/cli.js median 4 1 3 2` | `2.5` |

### Вимоги до чисел і виводу

- Число — ціле або десяткове, можливо від’ємне: `7`, `-3`, `2.5`, `-0.75`. Роздільник — **крапка**.
- Не є числами: `abc`, `1,5`, `12px`, порожній рядок, `NaN`, `Infinity`.
- Результат виводиться в **stdout** одним рядком, округлений **не більше ніж до 2 знаків** після крапки без зайвих нулів: `1.5`, `1.33`, `0.3`, `42`.

### Довідка

`--help` або `-h` виводить у stdout довідку, що починається з `Usage:` і перелічує всі операції. Код виходу — `0`.

### Помилки та коди виходу

Повідомлення про помилку виводиться в **stderr** і починається з `Error:`; stdout при цьому порожній.

| Ситуація | Код виходу |
|---|---|
| успішне обчислення, довідка | `0` |
| немає аргументів, невідома операція (регістр має значення: `SUM` — помилка) | `1` |
| операцію вказано, але не передано жодного числа | `2` |
| хоча б один аргумент не є коректним числом | `3` |

3. На захисті (лаб. 2) ви демонструєте роботу утиліти й пояснюєте свій код.

## Підказки

- `process.argv` — масив аргументів; перші два елементи — шлях до node і до скрипта.
- Код виходу задається через `process.exitCode = N` (або `process.exit(N)`).
- Вивід: `console.log(...)` → stdout, `console.error(...)` → stderr.
- Корисне: `Number()`, `Number.isFinite()`, регулярні вирази, `Array.prototype.reduce`, `sort((a, b) => a - b)`.
